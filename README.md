# TypeScript Project – TTip Calculator App

This is my solution for the FrontEnd Mentor Challenge.
It is a small Application that calculates a given amount of Tipping money. 

It does not send any data to a backend is just for demonstration.

## Features

    1. Mobile-first design with Tablet and Desktop support
    2. Typescript and Input Validation
    3. Dynamic Grid Layout
    4. Using SCSS for styling

## Tech-Stack

Typescript, HTML5, CSS3, SCSS

## Key learning Goals
- Improving my Typescript skills
- Improving my Ability to use SCSS, to not overwrite too many properties.


## This Project did not use LLM's to generate the code.

As this is a learning Project, I did not use any LLM's to generate the code.
That would defeat the purpose of this project.
I used the started code provided by FrontendMentor for the challenge.
